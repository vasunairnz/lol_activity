# Discord Live League of Legends Activity Display
## The Goal:
Have my discord activity display live data from my leauge of legends game including the Gamemode, Champion I'm playing, CS, KDA etc.

I also will aim to add a icon for the champion being played. I wish to make the icons custom drawings of each champion


## The Back End:
Using API's from the League developer portal I am able to call for local live data when I am in a league game. I call for data, once I get a return I know that I am in a game and begin calling for data more regularly and save the desired data. This data will then be displayed in the front end

## 
The data will be displayed under the activity tab of my profile on discord whenever I am in game.
